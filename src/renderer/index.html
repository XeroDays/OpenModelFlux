Paste the full chat completions endpoint. OpenRouter is the default. Any OpenAI-compatible server works if it uses the same protocol (OpenAI, Groq, Ollama, LM Studio, and similar).
Paste the API key from your provider. For OpenRouter, generate one in the dashboard. Local servers can use a dummy value if they do not require a key.
Enter the model ID your provider expects (e.g. openai/gpt-oss-120b:free on OpenRouter).
Controls how much step-by-step reasoning the model uses before replying. None turns it off; higher levels think longer and may use more tokens.
